# ξ Dark Energy · BAO MCMC

**Reproducible Bayesian MCMC inference for dark energy model comparison.**

> Pantheon+SH0ES supernovae + DESI DR2 BAO · ΛCDM · CPL · Ξosc · emcee · v0.1.0-exploratory

---

:::caution Exploratory release
This project is released as `v0.1.0-exploratory`. The oscillating dark energy model (Ξosc)
shows a marginal preference for non-zero oscillation amplitude, but this is **not sufficient
to claim detection**. See [Known Limitations](./results/caveats).
:::
