Since the beginning of the **AstroSpectro** project, the notebook `[02_tools_and_visuals.ipynb](https://github.com/PhD-Brown/AstroSpectro/blob/main/notebooks/02_tools_and_visuals.ipynb)` served as an exploratory notebook. It was where I tested spectrum visualizations, line detections, and diagnostics. But as the tools accumulated, the code became monolithic and difficult to maintain.

{/* truncate */}

## Refactoring Goals

I undertook a complete refactor with three objectives in mind:
- **Clarity**: each tool must be readable, self-contained, and clearly named
- **Reusability**: functions must be modular and usable elsewhere
- **Explorability**: interactivity must make exploration more intuitive and scientific

## Final Architecture

All the logic now lives in `src/tools/[visualizer.py](https://github.com/PhD-Brown/AstroSpectro/blob/main/src/tools/visualizer.py)`, in the form of a class:

```python
visualizer = AstroVisualizer(paths)
```

Each interactive tool (header explorer, augmented spectrum, peak tuning, sky map, model inspector) becomes a simple call:

```python
visualizer.interactive_spectrum_analyzer()
visualizer.plot_sky_coverage()
```

## New Integrated Tools

- Dynamic FITS Header Explorer
- Augmented Spectrum Analyzer (flux + lines + SNR + sliders)
- Interactive tuning of detection parameters (`prominence`, `window`)
- Analysis of zeros in the extracted features
- Sky coverage map (Mollweide projection)
- `.pkl` model inspector: hyperparameters + feature importance

## Impact on the Project

This refactor allows me to:
- Save time when iterating on features and models
- Work more like in a real lab
- Prepare the pipeline extension toward spectral cubes (SITELLE, etc.)
