Today marks a major milestone for the AstroSpectro project: the structure and core content of the documentation for version `v0.1.0-alpha` are officially complete!

{/* truncate */}

It has been an incredible journey, going from a simple `README.md` to a full Docusaurus site, with a custom design, automated CI/CD deployment, and structured guides.

### What has been accomplished:

-   **An immersive homepage** with a strong visual identity.
-   **Documentation structured** by intent: Quick Start, Scientific Context, Practical Guides, etc.
-   **Polished pages with React/MDX** for an interactive user experience.
-   **A fully automated deployment workflow** via GitHub Actions.

This solid foundation will allow us to focus confidently on the next phase: continuously improving the pipeline and implementing the features from the **[Roadmap](/research-docs/docs/astrospectro/community/roadmap)**.

Thank you to everyone following the project. The journey is only just beginning!
