AstroSpectro is a fully automated, physics-informed pipeline that classifies stellar spectra
into five Harvard spectral types (A, F, G, K, M) from 99 spectroscopic descriptors derived
from N = 349,998 LAMOST DR5 × Gaia DR3 cross-matched spectra.
SHAP post-hoc interpretability reveals that metallicity-sensitive features —
Ca II H&K and Mg b — rank *above* the classical Balmer temperature proxies in the global
importance structure of the trained classifier, challenging the primary-temperature assumption
of the MK system. This result is the central scientific contribution of the project and the
focus of a manuscript in preparation.

## What is AstroSpectro?

AstroSpectro addresses a long-standing question in stellar astrophysics:
*which physical indicators drive a modern ML classifier when trained on a large
spectroscopic survey?*
The pipeline ingests raw LAMOST DR5 FITS spectra, extracts 183 physics-motivated features
spanning atomic lines, molecular band indices, continuum slopes, and Lick/IDS spectral
indices, cross-matches with Gaia DR3 for astrometric and photometric anchoring, and trains
a gradient-boosted classifier with full SHAP post-hoc interpretability.

## Scientific purpose

AstroSpectro exists to investigate a deceptively simple question: when a machine learning
classifier is trained on a large stellar spectroscopic survey, *which physical indicators
actually determine its decisions?*

The classical MK spectral classification system places effective temperature — traced by
Balmer series strength — at the centre of the A/F/G/K/M hierarchy.
Modern surveys like LAMOST DR5 now make it possible to train classifiers on hundreds of
thousands of spectra and then interrogate those models via post-hoc interpretability
methods. AstroSpectro does exactly this, with four explicit scientific goals:

- **Classify** stellar spectra into five Harvard types (A, F, G, K, M) with calibrated
  confidence, using only features derivable from the spectrum itself.
- **Extract** physically meaningful descriptors that encode astrophysical observables —
  line strengths, profile shapes, molecular band indices — rather than raw flux pixels.
- **Validate** what the model learns against independent stellar parameters from Gaia DR3,
  confirming or challenging the astrophysical coherence of the classification structure.
- **Avoid** observational shortcuts: positional, temporal, and survey-specific metadata
  are excluded at the architectural level via `spectro_only = True`.

:::note F/G boundary
F and G classes show the lowest F1 scores (0.822 and 0.861 respectively), consistent with
the spectral continuum at the F/G boundary (~5,000–6,500 K). The UMAP projection confirms
this overlap is a physical continuum, not a modelling artefact. See
[Science — F/G Confusion Analysis](./science/fg-confusion) for the full investigation.
:::

## Central scientific finding

:::tip Key finding
**SHAP analysis reveals that metallicity-sensitive features (Ca II H&K and Mg b) rank
above classical Balmer temperature proxies** in the global feature importance of a
classifier trained on N = 349,998 LAMOST DR5 × Gaia DR3 spectra.
This result challenges the traditional MK spectral classification framework, where
effective temperature (traced by Balmer series strength) is considered the primary
classification discriminant.
:::

### SHAP global top-10 features

| Rank | Feature | Mean \|SHAP\| | Family | Category |
|---|---|---|---|---|
| **1** | `feature_index_CaH2` | 0.297 | Ca II | Physical (spectroscopic) |
| **2** | `feature_Mg_b_eq_width` | 0.271 | Mg b | Physical (spectroscopic) |
| **3** | `feature_Hα_eq_width` | 0.252 | Hα (Balmer) | Physical (spectroscopic) |
| 4 | `feature_index_Hbeta_index` | 0.194 | Hβ (Balmer) | Physical (spectroscopic) |
| 5 | `feature_CaIIK_eq_width` | 0.191 | Ca II | Physical (spectroscopic) |
| 6 | `feature_slope_deep_red` | 0.157 | Continuum | Physical (spectroscopic) |
| 7 | `feature_index_G4300` | 0.143 | Mol. CN/CH | Physical (spectroscopic) |
| 8 | `feature_index_CN_2` | 0.117 | Mol. CN/CH | Physical (spectroscopic) |
| 9 | `feature_index_Mg_2` | 0.114 | Mg b | Physical (spectroscopic) |
| 10 | `feature_CNO_index` | 0.110 | Mol. CN/CH | Physical (spectroscopic) |

<span className="badge badge--success">🔭 Discovery</span>

Ca II H&K features occupy **ranks 1 and 5** globally; Mg b occupies **rank 2**.
The first Balmer line (Hα) appears only at rank 3. This ordering confirms that the
classifier has learned a **metallicity-first, temperature-second** discriminant structure —
consistent with the role of Ca II H&K as a [Fe/H] proxy in late-type stars.

<details>
<summary>Physical interpretation of the top feature families</summary>

| Family | Dominant class sensitivity | Physical meaning |
|---|---|---|
| **Ca II (H&K, triplet)** | G, K, M | Surface gravity + metallicity proxy; maximal near 4,500 K |
| **Mg b (5167–5183 Å)** | G, K | Lick Mg b index — atmospheric [Mg/Fe]; strengthens in metal-rich dwarfs |
| **Hα / Hβ (Balmer)** | A, F | T_eff proxy; peaks ~10,000 K; weakens in cool stars |
| **Mol. CN/CH (G-band)** | G, K | Carbon chemistry; sensitive to luminosity class and [C/Fe] |
| **Mol. TiO/VO** | M | T_eff < 4,000 K flag; highly class-specific for M dwarfs |
| **Continuum slope** | A → M | Pseudo-colour proxy correlated with T_eff and extinction |

</details>

## Dataset at a glance

| Property | Value | Notes |
|---|---|---|
| Survey | LAMOST DR5 | Low-resolution (R ≈ 1,800) optical survey |
| Cross-match | Gaia DR3 | CDS XMatch · `vizier:I/355/gaiadr3` · GSP-Phot parameters |
| Total spectra (raw) | ~250,000 downloaded | ~139k still unprocessed |
| Total spectra (used) | 349,998 | After class filter (excl. B, C, D, S, W, s) |
| Training set | 229,274 | 65 % stratified split · random state 42 |
| Test set | 60,947 | 17.4 % — held out throughout |
| Features (engineered) | 183 | All spectroscopic · `spectro_only = True` |
| Features (selected) | 99 | Post-importance pruning |
| Classes | A, F, G, K, M | 5 Harvard spectral types |
| Wavelength range | 3,700–9,000 Å | LAMOST low-resolution optical arm |
| SNR quality filter | SNRg > 10 | Applied at dataset-build step |
| Excluded classes | B, C, D, S, W, s | 1,668 rows removed — rare / degenerate |

:::warning Known limitation
The Gaia DR3 GSP-Phot parameters (`teff_gspphot`, `logg_gspphot`, `mh_gspphot`) are
available for ~40 % of the cross-matched sample. Validation plots and correlations are
computed on this subset. The classification model itself uses only LAMOST-derived
spectroscopic features (`spectro_only = True`) and is not affected by this incompleteness.
:::
