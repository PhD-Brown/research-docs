# Guide: Model Training

Once the feature set has been extracted, the `SpectralClassifier` class orchestrates model training, optimization, and evaluation. It encapsulates a complete `scikit-learn` / `imblearn` pipeline, supports about a dozen models, and automatically logs results to Weights & Biases.

:::info[Starting point]
All training logic is in [`src/pipeline/classifier.py`](https://github.com/PhD-Brown/AstroSpectro/blob/main/src/pipeline/classifier.py). The orchestration notebook is `00_master_pipeline.ipynb`.
:::

---

## Quick start

```python
from src.pipeline.classifier import SpectralClassifier

# XGBoost training in pure spectroscopic mode
clf = SpectralClassifier(model_type="XGBoost", prediction_target="main_class")
clf, feature_cols, X, y = clf.train_and_evaluate(
    features_df,
    spectro_only=True,    # excludes ra, dec, redshift, Gaia — publication mode
)

# Save artifacts
clf.save_model("data/models/spectral_classifier_xgboost.pkl")
```

## 2. The training process

### Data preparation

`SpectralClassifier` automatically prepares the data before training:

1. **Cleaning:** Spectra without a valid `subclass` and classes with < 10 samples are excluded.
2. **Feature selection:** In `spectro_only=True` mode, all non-spectral columns are filtered out.
3. **Train/test split:** 80/20 stratified by class.

### Pipeline and W&B tracking

<TrainingPipelineFlow />

### Hyperparameter tuning

**Option A — GridSearchCV (default):**

```python
# Stratified cross-validation k=5 · metric: balanced_accuracy
clf.train_and_evaluate(features_df, spectro_only=True)
```

**Option B — Optuna (Bayesian optimization):**

The Optuna infrastructure is deployed for large-scale exploration. It is especially useful for exploring `n_estimators`, `max_depth`, `learning_rate`, `colsample`, `subsample`, `reg_alpha`/`lambda` on the ~139k available spectra.

```python
clf.train_and_evaluate(
    features_df,
    spectro_only=True,
    tuner="optuna",
    n_trials=200,
)
```

## 3. `spectro_only=True` mode

:::caution[Required for publications]
Enable this mode for all rigorous scientific results. It ensures that the model learns to classify stars from their **intrinsic physics only**, without any observational bias.
:::

```python
clf.train_and_evaluate(features_df, spectro_only=True)
```

**Automatically excluded features:**
- Angular coordinates: `ra`, `dec`
- Observing conditions: `redshift`, `seeing`, `snr_*`, `jd`, `fiber_id`, `magnitude_*`
- Gaia columns: `parallax`, `bp_rp`, `teff_gspphot`, `logg_gspphot`, `M_G`, `v_tan_kms`, etc.

`ra`, `dec` and `redshift` are excluded because they can correlate with spectral type through LAMOST observational biases (observation programs targeted by type) rather than through stellar physics. The exported run reports do not show a measurable accuracy gain from this exclusion: in the 100k runs, v3 (before `spectro_only`) and v4 (`spectro_only`) reach a balanced accuracy of <RunFact run="20260306T011253Z" path="metrics.balanced_accuracy" format="pct" /> and <RunFact run="20260306T013341Z" path="metrics.balanced_accuracy" format="pct" /> respectively, and v5 (`spectro_only` plus isotonic calibration) <RunFact run="20260306T020848Z" path="metrics.balanced_accuracy" format="pct" />.

In practice, `spectro_only` does not remove every Gaia column: the reference run still selected four Gaia/photometric features.

## 5. Complete evaluation

After training, `clf.evaluate()` automatically generates:

```python
clf.evaluate(X_test, y_test, plot=True)
```

| Output | Description |
|:---|:---|
| Classification report | Precision / Recall / F1 by class (A, F, G, K, M) |
| Confusion matrix | Normalized — shows the expected F/G confusion |
| ROC and PR curves | One-vs-rest by class |
| ECE score | Expected Calibration Error — probability quality |
| Feature importance | XGBoost gain or permutation importance |

## 6. Reproducibility

Each run produces a unique ISO timestamp identifier. To reproduce an exact run:

```python
# Retrieve the training source file
import json
with open("data/reports/20260213T225019Z/spectral_classifier_xgboost_20260213T225019Z_meta.json") as f:
    meta = json.load(f)

print(meta["trained_on_file"])     # → the features CSV used for training
print(meta["best_params_"])        # → final hyperparameters
print(meta["n_features_used"])     # → number of features used by this run
print(meta["balanced_accuracy"])   # → balanced accuracy of this run
```
