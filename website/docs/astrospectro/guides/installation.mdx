# Installation

Welcome to the **AstroSpectro** pipeline installation page!  
You have two options to get started: via the cloud with GitHub Codespaces (simple and fast) or manually on your local machine.

> For detailed explanations, see the [User Guides](/research-docs/docs/astrospectro/guides/).

---

## Option 1 — GitHub Codespaces (Recommended)

This is the simplest method. It requires **no installation** on your computer.

### Step 1 — Create the Codespace

1. Go to the **[project GitHub repository](https://github.com/PhD-Brown/AstroSpectro)**.
2. Click **`< > Code`** → **Codespaces** tab.
3. Click **`Create codespace on main`**.

- Click **Select Kernel** (top right)

### Step 5 — Managing your Codespace (Important)

If you use GitHub Codespaces, keep in mind that usage consumes compute minutes (limited, even for students).

:::warning[Don't confuse "Stop" and "Delete"]
- **⏸️ Stop:** Pauses the machine. Your files, downloaded data, and `.env` environment are **saved**. This is the recommended action when you finish for the day.
- **🗑️ Delete:** Completely destroys the environment. Any work not saved to GitHub (via `git push`) will be **lost**. Use this only for cleanup.
:::

**How to stop cleanly:**
1. Go to your dashboard: [github.com/codespaces](https://github.com/codespaces).
2. Click the three dots `...` next to your active instance.
3. Select **Stop codespace**.

*(Note: By default, Codespaces also stops automatically after 30 minutes of inactivity.)*

## Option 2 — Manual Local Installation

This method installs the project on your own machine. Make sure you have the following prerequisites:

- **Python 3.11** (recommended and tested version).
  - *Note: Python 3.9+ may work but is not guaranteed.*
- **Git** installed.
- (Optional) **JupyterLab** or VS Code to run notebooks.

### Step 1 — Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/PhD-Brown/AstroSpectro.git
cd AstroSpectro
```

### Step 2 — Install (Two methods)

Choose the method that suits you best.

#### ⚡ Method A — Automatic Installation (Recommended)

We provide scripts that create the virtual environment, install dependencies,
and configure the Jupyter kernel for you in a single command.

**On Windows (PowerShell):**
```powershell
# 1. Allow script execution (temporary for this window)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 2. Run the script
.\scripts\setup.ps1
```

**On macOS / Linux:**
```bash
# Grant execution permissions if needed
chmod +x scripts/setup.sh
# Run the script
bash scripts/setup.sh
```

#### 🛠️ Method B — Manual Installation (Step by step)

If you prefer to control each step or if the scripts don't work, follow this procedure:

**1. Create and activate the virtual environment**

```bash
# Create
python -m venv venv

# Activate
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Windows (CMD):
.\venv\Scripts\activate.bat
# macOS/Linux:
source venv/bin/activate
```

**2. Install the project and its dependencies**

The `-e .` option is crucial for development. We use `python -m pip` to guarantee
installation in the correct environment.

```bash
python -m pip install --upgrade pip
python -m pip install -e .
python -m pip install -r requirements.txt
```

**3. Register the kernel for Jupyter**

This step allows Jupyter to recognise your virtual environment under the name "AstroSpectro".

```bash
python -m pip install ipykernel
python -m ipykernel install --user --name astrospectro --display-name "AstroSpectro (Py3.11)"
```

### Step 3 — Configuration (`.env`)

As with the cloud option, you need to configure your access credentials.

Rename the **`.env.example`** file to **`.env`** and fill in your
**[Gaia connection credentials](/research-docs/docs/astrospectro/guides/downloading-data)**.

:::danger[Important]
**Never** commit your `.env` file to GitHub. It contains your passwords.
:::

### Step 4 — Installation complete!

Your local environment is now ready: the virtual environment is activated, the project is
installed in editable mode, and the kernel is registered.
