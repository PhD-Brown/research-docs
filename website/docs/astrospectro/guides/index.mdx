# Practical Guides

Welcome to the practical guides for the **AstroSpectro** project. This section walks you through each key step of the pipeline with concrete, task-oriented tutorials.

The goal here is to show you **how** to complete specific actions: use a pipeline step independently, explore a function in greater depth, or adapt parameters to your needs.


:::tip[Start here]
New to AstroSpectro? Follow this route:

1. **[Installation](./installation.mdx)**: prepare your Python environment, or open a Codespace.
2. **[Quick Start](./quick-start.mdx)**: run the whole pipeline once, from downloading spectra to the first predictions.
3. **Then go deeper**: the guides below for each step, [Concepts & Architecture](../concepts/index.mdx) for the reasoning, the [API Reference](../api/index.md) for classes and functions.

Stuck? Check the [FAQ](../community/faq.md) or [open an issue](https://github.com/PhD-Brown/AstroSpectro/issues/new).
:::
