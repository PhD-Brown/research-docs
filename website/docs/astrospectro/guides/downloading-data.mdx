# <FontAwesomeIcon icon={faDownload} /> Guide: Data Download

> This practical guide shows you how to use the pipeline's interactive interface to retrieve LAMOST DR5 spectra. The underlying logic is encapsulated in the [**`SpectraManager`**](https://github.com/PhD-Brown/AstroSpectro/blob/main/src/tools/spectra_manager.py) and [**`SmartDownloader`**](https://github.com/PhD-Brown/AstroSpectro/blob/main/src/tools/dr5_downloader.py) modules.

## <FontAwesomeIcon icon={faCogs} /> How It Works

Downloading is orchestrated by the **`notebooks/01_download_spectra.ipynb`** notebook. Under the hood, it uses the `SmartDownloader` class, which implements robust and "reproducible" logic:

<details>
  <summary>Click to view the details of the <code>SmartDownloader</code> logic</summary>
  <div>
    <ol>
      <li><strong>State Management:</strong> It checks <code>data/catalog/downloaded_plans.csv</code> to skip observation plans that were already fully downloaded in previous sessions.</li>
      <li><strong>File Scraping:</strong> For each new plan to process, it scrapes the official LAMOST web page to list all available <code>.fits.gz</code> files.</li>
      <li><strong>"Round-Robin" Downloading:</strong> To guarantee dataset diversity, it does not download plans one after another, but alternates between them (one spectrum from plan A, then one from plan B, etc.).</li>
      <li><strong>Real-Time Progress Bar:</strong> An interactive progress bar is displayed to track download progress.</li>
      <li><strong>State Update:</strong> Once the session is complete, it updates the log with the plans that are now complete.</li>
    </ol>
  </div>
</details>
