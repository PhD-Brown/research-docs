# <FontAwesomeIcon icon={faSpinner} /> First Run: From A to Z

Now that your environment is configured, we will run the complete pipeline through the main notebook: `00_master_pipeline.ipynb`.
This notebook orchestrates every step, from data selection to the generation of a session report.

## <FontAwesomeIcon icon={faCogs} /> Step 2: Run the Complete Pipeline

Once you have data:

1. Open the main notebook: `notebooks/00_master_pipeline.ipynb`.

The notebook runs the `MasterPipeline` sequentially:

- **It initializes the environment**, sets up access to **Gaia**, and creates or validates the required directory structure. The first connection may take a little while.
- **Batch selection:** simply define the number of desired spectra, for example `batch_size=1000`, and keep the default strategy, `random`.
- **Local catalog generation** for the selected batch.
- **Processing & feature extraction**, with several dozen possible features depending on the configuration.
- **Training & evaluation** through an interactive interface.

### Training (recommended first run)

In the training interface, you can choose several models, such as `XGBoost`, `RandomForest`, `SVM`, `ExtraTrees`, `KNN`, `MLP`, and others, and adjust their hyperparameters.

> **Goal:** validate that the full chain works, not optimize performance.

For a **first run**, keep things simple:

- For an initial run, we recommend **XGBoost** or **RandomForest**. They are fast and robust. You can explore the other models afterward.
- Keep the default values, or use a template/preset if one is available.
- Launch the batch/run.

## <FontAwesomeIcon icon={faPoll} /> Step 3: Review the Results

At the end of the run, several artifacts are produced:

- A **CSV** file in `data/processed/`, containing features ready for analysis.
- A **`.pkl`** model in `data/models/`.
- A **JSON session report** in `data/reports/`, along with result-analysis figures such as `feature_importance`, `roc`, `confusion_matrix`, `precision_recall`, and others.
