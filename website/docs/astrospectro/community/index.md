# Community & Contributions

AstroSpectro is a research project that is still changing, and every contribution, small or large, helps. This section is the place to ask questions, propose ideas, find out how to take part, and see what is planned.

Whether you use the pipeline, read the code or work on a related analysis, there are several ways to get involved.

## Acknowledgements and contact

This work relies on public survey data and open-source tools; the [Acknowledgements](./acknowledgements.md) page names them and gives the standard acknowledgement texts for LAMOST and Gaia.

For a private discussion, a collaboration or a specific question, write to [albak1@ulaval.ca](mailto:albak1@ulaval.ca). For anything that others could benefit from (a bug, a documentation error, a suggestion), an [issue on GitHub](https://github.com/PhD-Brown/AstroSpectro/issues/new) is better: it stays visible.
