# The Data: LAMOST DR5

The **AstroSpectro** pipeline is built on the scientific exploitation of stellar spectra from the **LAMOST Data Release 5 (DR5)**. This wide-field spectroscopic survey represents one of the richest astrophysical databases in the world: several million spectra acquired at low resolution, covering the entire sky accessible from Xinglong, China.

---

## Telescope and survey characteristics

LAMOST (*Large Sky Area Multi-Object Fiber Spectroscopic Telescope*) is a unique instrument for its spectral multiplexing capabilities: 4,000 optical fibres can observe 4,000 objects simultaneously within a field of view of 5° diameter.

## Structure of a LAMOST FITS file

Each LAMOST DR5 spectrum is distributed in **compressed FITS** format (`.fits.gz`). A file typically contains several extensions:

- **Extension 0 (PRIMARY)**: Global header with observation metadata
- **Extension 1 (FLUX)**: Spectral flux array (3,921 float32 values)
- **Extension 2 (IVAR)**: Inverse variance (pixel-by-pixel quality)
- **Extension 3 (AND_MASK / OR_MASK)**: Defective pixel masks
- **Extension 4 (WAVELENGTH)**: Wavelength grid reconstructed from `COEFF0` and `COEFF1`

### Wavelength grid reconstruction

The λ grid is not stored explicitly but reconstructed from WCS coefficients:

```python
import numpy as np

# Wavelength grid reconstruction (log or linear depending on instrument)
coeff0 = header['COEFF0']   # λ₀ of the first pixel
coeff1 = header['COEFF1']   # Δλ / pixel

n_pixels = 3921
wavelength = 10 ** (coeff0 + coeff1 * np.arange(n_pixels))  # in Ångströms
# → [3690 Å ... 9100 Å]
```

### Local data architecture

```
data/
├── raw/                         # Raw FITS spectra
│   └── <planid>/                # Organised by observation plan

├── catalog/                     # Catalogues and logs

│   └── valid_plan_urls.csv      # Valid URLs extracted from the DR5 website
├── processed/                   # Extracted features

└── models/                      # Saved models
    └── spectral_classifier_xgboost_<ISO>.pkl
```

### SmartDownloader — Intelligent downloading

The `dr5_downloader.py` module implements **idempotent** download logic:

```python
from src.tools.dr5_downloader import SmartDownloader

downloader = SmartDownloader(
    data_dir="data/raw/",
    log_file="data/catalog/downloaded_plans.csv",
    n_workers=8,          # parallel download
)

# Start download — automatically resumes where it left off
downloader.run(urls_file="data/catalog/valid_plan_urls.csv")
```

**Smart logic:**
1. Consults `downloaded_plans.csv` to list already-complete plans
2. Filters already-downloaded URLs — avoids duplicates
3. Parallel download with error handling and retry
4. Logs each completed plan — progress is preserved between sessions

**Measured throughput:** ~340,000 spectra/hour (Ryzen 9 5950X, 1 Gbps connection).

## Positional cross-match with Gaia DR3

Each LAMOST spectrum is matched with its counterpart in Gaia DR3 (Gaia Collaboration, Vallenari et al., 2023) by angular coordinates, via `gaia_crossmatcher.py`:

```python
from src.pipeline.gaia_crossmatcher import GaiaCrossmatcher

matcher = GaiaCrossmatcher(
    radius_arcsec=1.0,   # tolerance radius: 1 arcsecond
    gaia_table="gaia_dr3_source.csv",
)

catalog_matched = matcher.crossmatch(lamost_catalog)
```

**Gaia DR3 parameters added:**

| Parameter | Symbol | Unit | Use in AstroSpectro |
|:---|:---:|:---:|:---|
| Effective temperature | Teff | K | PC1 validation (ρ = +0.831) |
| Surface gravity | log g | dex | Dwarf/giant validation |
| Metallicity | [Fe/H] | dex | PC2 validation |
| Photometric colour | G_BP − G_RP | mag | Teff correlation |
| Parallax | π | mas | Distance, absolute magnitude |
| Astrometric quality | RUWE | — | Quality filter: RUWE < 1.4 |

## Quality filters applied

Two sequential filters guarantee the quality of the final dataset:

| Filter | Criterion | Reason |
|:---|:---:|:---|
| Signal-to-noise ratio | `SNR_r > 10` | Ensures line detectability and reliability of equivalent widths |
| Astrometric quality | `RUWE < 1.4` | Excludes unresolved binary stars and Gaia measurement artefacts |

```python
# Filters applied in data_loader.py
mask_snr  = catalog['snr_r'] > 10
mask_ruwe = catalog['ruwe'] < 1.4
catalog_clean = catalog[mask_snr & mask_ruwe]
# N: 250,000 → 43,019 spectra retained
```
