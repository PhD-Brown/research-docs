# XGBoost — comparison on the same 183 features

This page documents the results of the supervised XGBoost classifier trained on the **same 183 spectroscopic features** used for PCA/UMAP/t-SNE dimensionality reduction. It establishes the link between the unsupervised approach (emergent structure in UMAP) and the supervised approach (classification with labels), demonstrating that both converge toward the same physical structure.

## Context and motivation

The conclusion of the PHY-3500 article (Baker, Caillat & Jean, 28 April 2026) opens with this perspective:

> "An XGBoost classifier trained on the same 183 features achieves a balanced accuracy of 87% on five spectral types (A, F, G, K, M), with a median confidence of 96.3% for its predictions projected in UMAP space. The geographic coherence of XGBoost predictions in the projection confirms that the supervised classifier and unsupervised dimensionality reduction methods capture the same physical structure: projections are not only visualisation tools, but also qualitative validation spaces for supervised models."

This result is central to AstroSpectro: it demonstrates that the 183 *pure* spectral features (without Gaia, without `ra`/`dec`/`redshift`) are sufficient for high-performance classification.

---

## Experimental configuration

### `spectro_only=True` mode

This result is obtained in **`spectro_only=True`** mode of `SpectralClassifier` — i.e., using *only* spectral features, without any observational metadata or Gaia features.

Variables excluded compared to the full model:
- `ra`, `dec` (angular coordinates)
- `redshift`, `seeing` (LAMOST observation conditions)
- `parallax`, `bp_rp`, `teff_gspphot`, `logg_gspphot` and other Gaia columns

This restriction guarantees that the model learns to classify stars from their **intrinsic physics** alone — the condition required for rigorous scientific publication and for application to data without Gaia cross-match.

### F/G confusion — the trickiest boundary

The main confusion of the model concentrates at the **F-G boundary** (5,500–6,200 K). These stars share similar Balmer and Ca II line widths, and the distinction relies on fine features (continuum asymmetry, Lick Mg b indices, Hβ). This ambiguity is visible in UMAP space: erroneous F/G predictions concentrate in the transition zone between the two populations — this is not a classifier error, but a reflection of **real physical continuity** in the spectral sequence.

## Geographic coherence in UMAP space

### Principle of supervised/unsupervised cross-validation

The UMAP projection of XGBoost predictions allows **qualitative validation** of the model: if the supervised classifier has learned the same physical structure as UMAP (unsupervised), predictions should follow the geography of the projection.
