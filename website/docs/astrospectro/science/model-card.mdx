## Intended use

**Intended users:** Researchers in stellar astrophysics, ML-for-astronomy practitioners, reviewers of the AstroSpectro manuscript.

**Intended use cases:**
- Automated classification of LAMOST DR5 stellar spectra into MK spectral types (A/F/G/K/M)
- Benchmarking interpretable ML methods on spectroscopic data
- SHAP-based analysis of which physical features drive spectral class separation

**Out-of-scope use cases:**
- Classification of non-LAMOST spectra without retraining (resolution mismatch: LAMOST R~1800)
- Subtype classification (e.g., G2V vs G8V) — the model predicts main class only
- Production astronomical catalog generation without manual validation of edge cases

---

## Training data

- **Source:** LAMOST DR5 (Low-Resolution Spectroscopic Survey)
- **Cross-match:** Gaia DR3 (CDS XMatch, radius 1.5 arcsec)
- **Classes retained:** A, F, G, K, M (excluded: B, C, D, S, W, s — 1,668 rows removed)
- **Class distribution (test set):** A=3,738 · F=12,803 · G=21,902 · K=13,642 · M=8,862
- **Train/test split:** 80/20 stratified

:::caution Class imbalance
The dataset is imbalanced (G class dominates at ~36%). The model uses balanced accuracy as the primary metric. Class-weighted evaluation is applied throughout.
:::

---

## Evaluation data

The test set is held out from all training, calibration, and feature selection steps. A strict 80/20 stratified split is applied once at the start of each experiment. No data leakage was detected in the feature audit (see [Data Leakage Audit](../concepts/data-leakage-audit)).

---

## Known limitations

1. **Survey-specific features:** The model was trained on LAMOST R~1800 spectra. Transfer to higher-resolution surveys (APOGEE, GALAH) requires retraining.
2. **No subtype resolution:** The model classifies into 5 main MK types only.
3. **SHAP replication:** The Mg b dominance finding has not been replicated on an independent dataset.
4. **Gaia dependency:** 6 Gaia features are used — this requires a Gaia cross-match for any new spectra.
5. **Rare classes excluded:** B, C (carbon), D (white dwarf), S, W (Wolf-Rayet) stars are not classified.

---

## Ethical considerations

This is a research model for astronomical spectral classification. No sensitive personal data is involved. The LAMOST and Gaia datasets are publicly available under standard astronomy data policies. The model card is provided to prevent misrepresentation of classification performance in downstream communications.
