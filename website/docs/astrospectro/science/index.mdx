# Scientific Context

Welcome to the scientific section of the **AstroSpectro** project.

This section covers the scientific foundations behind the pipeline design. Beyond the technical aspects, it explains:

- The origin and characteristics of the spectroscopic data used,
- The methodology for processing spectra through to classification,
- How model performance is evaluated and outputs interpreted.

:::info[Who is this for?]

This section is for readers who:

- are new to computational astrophysics,
- want to understand the origin and processing of LAMOST spectra,
- want to connect model outputs to their scientific meaning.

:::
