## Three research projects

| Project | Description | Status |
|---------|-------------|--------|
| **[AstroSpectro](./docs/astrospectro/)** | Interpretable ML for stellar spectral classification — LAMOST DR5 × Gaia DR3 · 183 features · 87% balanced accuracy | `v1.0` |
| **[AstroVision](/research-docs/astrovision/overview/)** | Deep learning for galaxy morphological classification — DINOv2 + morphometrics · 86.3% balanced accuracy | `active` |
| **[ξ Dark Energy](/research-docs/xi-dark-energy/overview/)** | Bayesian MCMC comparing ΛCDM, CPL, and Ξosc dark-energy models | `v0.1.0-exploratory` |
