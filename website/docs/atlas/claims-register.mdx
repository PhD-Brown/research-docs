# ⚖️ Scientific Claims Register

This page centralizes every major scientific claim made across the three research projects. Each claim is assigned an **evidence level**, linked to its primary figure and documentation page, and annotated with known limitations or caveats.

:::info Purpose
This register exists to prevent overstating results — in conversations, in documentation, and especially in any future manuscript submissions. If a claim is not listed here with a supporting figure and run ID, it should not be stated as a finding.
:::

---

## Evidence levels

| Level | Meaning |
|---|---|
| ✅ **Solid** | Reproduced across multiple runs, consistent with physical expectations, no known confounders |
| 🟡 **Suggestive** | Present in primary results but not yet replicated across independent datasets or model families |
| 🔶 **Preliminary** | Single run or dataset, treated as hypothesis-generating, not conclusive |
| ⚠️ **Caveat** | Result is real but requires explicit qualification before public communication |

## How to update this register

When a new result is produced:
1. Add a row to the appropriate section above
2. Assign an evidence level honestly
3. Link the figure filename and the documentation page
4. Add any associated caveat immediately

This register is the **single source of truth** for what is claimed publicly. It takes precedence over any other documentation page in case of conflict.
