# Limitations

AstroVision results: limitations.

:::info Under construction
This page is actively being developed. Core content is added progressively.
:::

## What this page covers

- Disturbed galaxy recall ceiling ~0.53 — physically irreducible
- Small training set for some classes
- 64×64 pixel resolution limits fine morphological detail
- DINOv2 pretrained on natural images, not astronomical
