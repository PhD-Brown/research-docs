## What this page covers

- Open-source galaxy morphological classification pipeline
- Scientific question: do self-supervised visual representations encode physical galaxy structure?
- Dataset: Galaxy10 DECaLS, 17,736 images, 10 morphology classes
- Best result: 86.3% balanced accuracy (late-fusion multimodal)
