# Roadmap

This page tracks the next scientific, technical, and editorial milestones for AstroVision. The purpose is not to list every small task, but to make the direction of the project clear to readers, supervisors, collaborators, and future reviewers.

:::info[Current phase]
AstroVision is in a consolidation phase: the main architecture exists, the strongest result is the late-fusion multimodal model, and the next step is to strengthen reproducibility, uncertainty analysis, and manuscript readiness.
:::

## Scientific priorities

### 1. Consolidate the late-fusion result

The current headline result is the late-fusion multimodal model, reported at approximately **86.3% balanced accuracy**. This should remain the central result, but it needs to be documented with full context.

Required next steps:

- [ ] Verify final train/validation/test split.
- [ ] Export final confusion matrix.
- [ ] Export per-class precision, recall, and F1.
- [ ] Document whether metadata improves specific classes more than others.
- [ ] Add a clean ablation table: image-only, metadata-only, late fusion.
- [ ] Add the final claim to the Scientific Claims Register.

### 2. Make calibration findings explicit

The uncertainty page should not only report successful techniques. It should also preserve the finding that Temperature Scaling did not improve the late-fusion model in the current run.

Required next steps:

- [ ] Add reliability diagram.
- [ ] Add ECE table before/after calibration.
- [ ] Explain why Temperature Scaling may fail for this setting.
- [ ] Compare MC Dropout uncertainty against correctness.
- [ ] Connect conformal prediction to scientifically cautious classification.

### 3. Strengthen the physical interpretation

AstroVision should avoid becoming a pure computer-vision benchmark. The strongest version of the project explains what the model appears to learn about galaxy structure.

Required next steps:

- [ ] Link Grad-CAM examples to physical regions of galaxies.
- [ ] Compare morphology classes using morphometry descriptors.
- [ ] Add representative success and failure cases.
- [ ] Identify which classes are physically ambiguous rather than merely computationally hard.
- [ ] Clarify why disturbed galaxies remain difficult.

## Manuscript preparation

AstroVision is a natural candidate for a compact methods-and-results manuscript if the following pieces are completed.

### Minimum manuscript-ready package

- [ ] Abstract-level project framing.
- [ ] Dataset and preprocessing section.
- [ ] Model architecture figure.
- [ ] Benchmark table.
- [ ] Confusion matrix.
- [ ] Calibration / uncertainty figure.
- [ ] Grad-CAM composite figure.
- [ ] Morphometry / physical interpretation figure.
- [ ] Limitations section.
- [ ] Reproducibility statement.
- [ ] Citation / release metadata.

### Suggested manuscript narrative

1. Galaxy morphology classification is visually rich but physically ambiguous.
2. Image-only deep learning provides strong baselines.
3. Foundation vision features help, but do not automatically solve all class ambiguities.
4. Late-fusion improves the scientific framing by combining visual representation with physically interpretable descriptors.
5. Uncertainty and conformal prediction are necessary because morphology labels can be ambiguous.
6. Failure cases, especially disturbed galaxies, are scientifically informative rather than merely technical errors.

## Release checklist

Before tagging a public release:

- [ ] Every sidebar page builds without broken links.
- [ ] Every major claim has a source figure or table.
- [ ] Every result page states the dataset/split/model version.
- [ ] The late-fusion result is framed with caveats.
- [ ] The disturbed-class limitation is clearly visible.
- [ ] The citation page includes release metadata.
- [ ] The documentation landing page links to AstroVision key results.
- [ ] The repository has a reproducible environment file.
- [ ] The final figures have consistent style and captions.
