# Results

This folder receives text summaries, CSV comparisons and MCMC chain files.

Generated files include:

- `summary_protocol1b_combined.txt`
- `model_comparison_combined.csv`
- `run_100000_96.log`
- `chains_<MODEL>_combined.npy`

The `.npy` chain files can be very large and are ignored by default in `.gitignore`. Consider uploading them as a GitHub Release artifact rather than committing them directly.
