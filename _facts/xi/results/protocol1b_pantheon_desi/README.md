# Protocol 1b results

This directory contains public-facing result summaries for the final 100000-step / 96-walker run.

Tracked files:

- `final_parameter_estimates.csv`
- `final_model_comparison.csv`
- `final_model_comparison.md`
- `summary_protocol1b_combined.txt` if you choose to include the raw text summary

Not tracked by default:

- `chains/*.npy` MCMC chains
- `*.log` terminal logs

The heavy chains can be stored locally or attached to a GitHub Release.
